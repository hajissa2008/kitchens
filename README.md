# 4D Kitchen Studio

Interactive 3D/4D kitchen model with VR, built from a site drawing (L-shaped room 500 × 400 cm, ceiling 297 cm).

**Live:** https://hajissa2008.github.io/kitchens/

Working appliances (gas burners, hood with light and fan speeds, ovens, microwave, fridge, dishwasher, tap, AC), bi-fold corner cabinets with hidden LED lighting, pull-out pantry, live cabinet and marble/granite countertop finishes, a 17-day 4D construction timeline, walk mode, guided tour and WebXR VR.
